# Enshrouded

> Vérifié sur une vraie install (SteamCMD 2278520 en `anonymous`, serveur 1.0.0.0 / build 26083076, octobre 2026), **sans** connexion d'un joueur (test des groupes en jeu : issue #152).

- **Exécutable** : `enshrouded_server.exe` à la racine, **un seul processus**, sa propre console. Client : `enshrouded.exe` → préfixe `enshrouded_server`. Install : 7,6 Go. Démarrage ~2 s (`[Session] 'HostOnline' (up)!`), monde chargé ~12 s. Aucun argument documenté, « Cmd-Parameters: » vide dans le log (`enshroudedConfig: { customArgs }`, `EnshroudedLaunchConfig`).
- **Config** : `enshrouded_server.json` à côté de l'exe, créé au 1er lancement et **réécrit à chaque démarrage** → `lockWhileRunning` + refus `CONFIG_LOCKED` côté main. UTF-8 sans BOM, **LF**, **tabulations**, flottants `0.500000`. Clés de 1er niveau : `name`, `saveDirectory`, `logDirectory`, `ip`, `queryPort`, `slotCount` (1-16), `tags` (non géré), `voiceChatMode`, `enableVoiceChat`, `enableTextChat`, `gameSettingsPreset`, `gameSettings`, `userGroups`, `bannedAccounts` (⚠️ la doc dit `bans` ; non géré). Plus de `password` depuis l'update 2 (un ancien `password` crée un groupe `default`).
- **Lecture / écriture** (`serverJson.ts`, défauts dans `defaults.ts`) : on patche **l'objet lu** (clés inconnues et ordre gardés), indentation détectée, `readIniText` / `writeIniText` pour l'encodage et les fins de ligne, `.backup` avant écriture ; après un enregistrement, le diff ne montre que les valeurs modifiées, plus `"tags": []` / `0.5` (sans effet). JSON illisible → `AppError("ENSHROUDED_CONFIG_INVALID")` et refus de démarrer (`startChecks.ts` via `PREPARE`).
- **gameSettings** : lus **seulement** si `gameSettingsPreset = "Custom"`. le log écrit alors `[server] Game Settings 'Custom'` suivi des valeurs lues. 38 clés en 1.0.0.0 (`flameLevelFogRemoval` 0-20 et `randomSpawnerAmount: "Automatic"` viennent du `enshrouded_server_readme.txt` livré, plus à jour que la doc Zendesk). `dayTimeDuration`, `nightTimeDuration`, `fromHungerToStarving` en **nanosecondes** dans le fichier, minutes dans Nexum (`DURATION_KEYS`, conversion dans le main). Hors bornes : ramené à la limite par le serveur ; texte invalide : le serveur ne démarre pas → listes pour les énumérations.
- **userGroups** : `name`, `password`, `canKickBan`, `canAccessInventories`, `canEditWorld`, `canEditBase`, `canExtendBase`, `reservedSlots`. 4 groupes créés par défaut avec mots de passe aléatoires. Champs inconnus repris du groupe de **même nom** (un groupe renommé les perd). Validation : noms non vides et uniques (`ENSHROUDED_GROUP_INVALID`), somme des places réservées ≤ `slotCount` (`ENSHROUDED_SLOTS_INVALID`). Groupe sans mot de passe = ouvert à tous → avertissement sur le Dashboard.
- **Ports** : seul port fixe **15637 UDP** (`queryPort`), le reste est éphémère. Règle `Enshrouded Server - Query (<port>)`.
- **Arrêt** : CTRL+C ignoré, `taskkill` sans `/F` refusé, **CTRL+Pause = arrêt propre** (« Trigger gameflow shutdown, exit: Ctrl_Break », monde sauvegardé, code 0, < 2 s) → `gracefulSignal: "ctrlBreak"`, vérifié aussi sur un processus adopté. Piège de test : un script qui partage la console du serveur reçoit le signal aussi → tester depuis une console séparée (`Start-Process`).
- **Sauvegardes** : `savegame/world0.ksd` + `savegame/backup/world0.ksd.backup-N` (copies tournantes du jeu). `getSavePath` résout `saveDirectory` depuis `serverPath` (absolu accepté).
- **Logs** : stdout **complet** (identique à `logs/enshrouded_server.log`) → pas de `logFile`. Très bavard (~200 lignes techniques au démarrage, bloc « Session » toutes les 30 s, ~370 lignes de statistiques à l'arrêt) → `ENSHROUDED_LOG_NOISE` (`logNoise.ts`). Messages Steam sur stderr (`breakpad minidump`, `MatchmakingServers interface`, `steam friends/user interface`, `Benchmark` manquant) : normaux, écrits sans `[ERR]`. Contient l'IP publique (`Public ipv4:`) et `Server SteamId: <n>` (masqués à l'export, `SERVER_STEAM_ID` dans `redactLog.ts`). Lignes de connexion des joueurs non vues (issues #152, #153).
- **Rejoindre** : liste du jeu (filtre serveurs dédiés) par `name` (`searchName`), ou favori Steam `IP:queryPort`.
- Pas d'API ni de RCON, pas de mods serveur. 16 joueurs max. RAM ~4,4 Go au repos (+100 Mo/joueur), 30 Go disque → `GamePlugin.requirements` (`{ ramGb: 6, diskGb: 30 }`).
- **UI Config** (structure de la page Valheim) : `GeneralSection`, `NetworkSection`, `DifficultySection` (`ButtonGroup` des presets), `GameSettingsSection` (`gameSettingsFields.ts` rendu par `ConfigGroup` + `ConfigField` partagés, bornes `FieldDef.min/max`), `AdvancedSection`, puis `UserGroupsSection` / `UserGroupRow` avec leur propre Enregistrer. Modifier un réglage fin passe le preset en `Custom` (`handleSettingChange`). Hooks `useEnshroudedConfig` / `useEnshroudedGroups` sur `useConfigLoad`.
